# Калькулятор процентов

Небольшое PWA-приложение: считает проценты, ставится на Android как обычное
приложение (иконка на рабочем столе, запуск без адресной строки) и работает
без интернета.

## Что умеет

| Режим | Что считает | Пример |
| --- | --- | --- |
| Процент от числа | `X%` от `Y` | 20% от 1500 = **300** |
| Доля в процентах | `X` — это сколько процентов от `Y` | 30 от 250 = **12%** |
| Прибавить процент | `Y ± X%` (переключатель «прибавить / вычесть») | 1500 + 20% = **1800** |
| Изменение в % | было `X`, стало `Y` — на сколько изменилось | 80 → 100 = **+25%** |

Под каждым ответом — подсказка с сопутствующими числами (остаток, разница,
сумма изменения). Нажатие на карточку результата копирует число в буфер обмена.

Остальное по мелочи: своя цифровая клавиатура (системная не выскакивает и не
перекрывает экран), кнопка `⇄` меняет числа местами, `C` очищает поле, второе
нажатие — оба поля. Тема подхватывается системная, светлая или тёмная.
Введённые значения сохраняются между запусками.

## Установка на Android

1. Открыть сайт в Chrome.
2. Меню (три точки) → **«Установить приложение»** (или «Добавить на главный экран»).
3. Иконка появится на рабочем столе, дальше приложение запускается само по себе,
   в полный экран и без интернета.

На iPhone то же самое делается через Safari: «Поделиться» → «На экран «Домой»».

## Разработка

Статика без сборки — можно открыть локально любым сервером:

```sh
python3 -m http.server 8000
# затем http://127.0.0.1:8000/
```

Открывать файл напрямую через `file://` не стоит: service worker в этом режиме
не регистрируется, офлайн проверить не получится.

### Файлы

```
index.html              разметка
styles.css              оформление и темы
app.js                  расчёты, клавиатура, состояние
manifest.webmanifest    описание PWA (имя, иконки, цвета)
sw.js                   service worker — офлайн-кэш
icons/                  иконки приложения
```

### Важно при изменениях

После правки любого файла поднимите `VERSION` в `sw.js` — иначе у уже
установленного приложения останется старая версия из кэша:

```js
const VERSION = 'v2';
```

Если добавляете новый файл, впишите его ещё и в список `ASSETS` там же.

## Публикация

Сайт раздаётся через GitHub Pages из ветки `main`
(Settings → Pages → Source: Deploy from a branch → `main` / `root`).
Все пути в проекте относительные, поэтому работает и в подкаталоге,
и на своём домене.
